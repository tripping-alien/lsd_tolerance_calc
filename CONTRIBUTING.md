# Contributing to LSD Tolerance Model

Thank you for your interest in contributing! This project is an open-source educational tool focused on pharmacology visual modeling and harm reduction.

## Guidelines

1. **Educational & Scientific Accuracy**: Updates to mathematical models must reference peer-reviewed pharmacokinetic or receptor literature.
2. **Client-Side Invariance**: The project must remain 100% client-side with zero telemetry or backend logging.
3. **Multilingual Quality**: When adding or refining translations in `index.html`, ensure RTL layout integrity for Hebrew and natural phrasing for English and Russian.

## Getting Started

1. Fork the repo and create your branch: `git checkout -b feature/improvement`.
2. Test changes in multiple browsers (Chromium, Firefox, Safari) and screen sizes.
3. Submit a clear, descriptive Pull Request.

Please adhere to our [Code of Conduct](CODE_OF_CONDUCT.md).
